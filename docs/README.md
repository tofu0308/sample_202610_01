内容を学習メモへ移す・機能が落ち着いたら、**ファイルごと削除してかまいません**（恒久ドキュメントではない）。

| ファイル                  | 用途                                                     |
| ------------------------- | -------------------------------------------------------- |
| `DESIGN_BARCODE_SCAN.md`  | 設計・チェックリスト。登録は §13、組織拡張の方向性は §14 |
